# MyWardrobe (Каталог одежды)

Приложение с графическим интерфейсом для ведения гардероба, создания образов и просмотра статистики.

## Техническое задание (ТЗ)
Приложение позволяет пользователю:
- Вести базу вещей (добавление, редактирование, удаление).
- Прикреплять фотографии к вещам (через диалог выбора файла или drag&drop).
- Искать вещи по названию и фильтровать по категориям.
- Создавать образы (комплекты) из имеющихся вещей.
- Добавлять вещи и образы в «Избранное».
- Просматривать статистику гардероба (по категориям, сезонам и цветам).
- Использовать горячие клавиши (F5 — обновить, Delete — удалить выбранную вещь).

## Используемые технологии
- **Python 3.10+**
- **PyQt5** — для создания графического интерфейса (интерфейс собран в QtDesigner).
- **SQLite3** — встроенная база данных для хранения вещей и образов.
- **PyInstaller** — для сборки standalone-версии (.exe).
- **QSS** — для кастомного оформления интерфейса (пастельные розовые тона).

Как запустить проект (из исходников)
Склонируйте репозиторий:
git clone https://github.com/lisa32ti/MyWardrobe.git
cd MyWardrobe

Создайте и активируйте виртуальное окружение:
Windows:
python -m venv venv
venv\Scripts\activate

macOS/Linux:
python3 -m venv venv
source venv/bin/activate

Установите зависимости:
pip install -r requirements.txt

Запустите приложение:
python main.py

## Как собрать standalone версию (.exe)

Для сборки используется **PyInstaller**. В корне проекта выполните команду:

pyinstaller --noconfirm --onefile --windowed --add-data "ui;ui" --add-data "assets;assets" --add-data "styles;styles" main.py
